vim
  Flags: none
  Example: vim file.txt
  Risk: Incorrect mode changes can cause unintended edits; always confirm you are in normal mode before running commands.

vim modes & keys
  Flags: none
  Example: i (insert), Esc (normal), :w (write), :q (quit), :wq (save & quit)
  Risk: Writing (:w) to system files without checking permissions can break configs.

nano
  Flags: none
  Example: nano file.txt
  Risk: Saving over system-managed files can overwrite critical configuration.

nano save/exit
  Flags: none
  Example: Ctrl+O (save), Enter (confirm), Ctrl+X (exit)
  Risk: Saving without reviewing changes may overwrite important data.

grep -r
  Flags: -r (recursive)
  Example: grep -r "ssh" /etc
  Risk: Recursive searches may expose sensitive configuration paths.

grep -v
  Flags: -v (invert match)
  Example: grep -v "error" /var/log/syslog
  Risk: Inverted searches can hide important warnings if used incorrectly.

grep -E
  Flags: -E (extended regex)
  Example: grep -E "error|fail" /var/log/syslog
  Risk: Complex regex patterns may match unintended lines.

awk '{print $N}'
  Flags: none
  Example: awk '{print $1, $3}' /var/log/auth.log
  Risk: Printing incorrect fields can misrepresent log data.

awk -F:
  Flags: -F: (set field separator to colon)
  Example: awk -F: '{print $1, $3}' /etc/passwd
  Risk: Parsing sensitive files like /etc/passwd requires caution to avoid exposing user details.

bash variable syntax
  Flags: none
  Example: myvar="hello"
  Risk: Forgetting quotes can cause word-splitting and unexpected behavior.

quoting variables
  Flags: none
  Example: echo "$myvar"
  Risk: Unquoted variables may expand into multiple words or glob patterns.

command substitution $()
  Flags: none
  Example: files=$(ls /etc)
  Risk: Using backticks instead of $() reduces readability and nesting reliability.

function syntax
  Flags: none
  Example: myfunc() { echo "run"; }
  Risk: Missing braces or using reserved names can break scripts.

tee -a
  Flags: -a (append)
  Example: echo "log entry" | tee -a logfile.txt
  Risk: Using tee without -a overwrites logs instead of appending.

exit codes
  Flags: none
  Example: echo $?   # check last command
  Risk: Ignoring non‑zero exit codes can hide failures in scripts.

if blocks
  Flags: none
  Example: if [ -f file.txt ]; then echo "exists"; fi
  Risk: Incorrect test syntax ([ vs [[ ]) can cause unexpected condition failures.

git init
  Flags: none
  Example: git init
  Risk: Running in the wrong directory creates unwanted repos.

git add
  Flags: none
  Example: git add file.txt
  Risk: Using git add . may stage unintended or sensitive files.

git commit
  Flags: none
  Example: git commit -m "message"
  Risk: Poor commit messages reduce traceability and debugging clarity.

git log
  Flags: none
  Example: git log --oneline
  Risk: Sharing logs publicly may expose commit history or sensitive metadata.
